# fullstack-app
A demo app built using :
>> Node.js as backend
>> React.js as frontend.
>> Terraform scripts are used for building and provisioning infrastructure.
>> Bash scripts are embedded to securely work on remote server for installing necessary setup.
>> Finally, docker is used containerize the environment to production-grade isolated container so host os configurations don't conflict with the project
>> AWS EC2 is used as remote server infrastructure.
>> Nginx is embedded to provide secure connections.
